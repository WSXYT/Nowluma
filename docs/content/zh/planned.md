## 重写内核

接入对话框会显示「重写内核」和「暂不可用」，原因写在选项下。它没有可选状态，也没有隐藏开关：

- 选择兼容内核不会自动“升级”到重写内核。
- 已保存的重写选择不会被强行改成兼容内核；当前阶段根本不能提交该选择。
- 外部重写尝试尚未完成，未随包发布；不要根据仓库里的实验代码声称它可用。
- 将来若开放，仍需要按账号主动确认并重新评估风险，不会预勾选或静默回退。

兼容内核使用随包原生组件，存在账号、数据安全与法律风险；确认不免除依法不可免除的责任，也不改变 GPL 源码许可。

## 平台

- **Linux Docker amd64**：自动化构建与全新 HOME 的 smoke 已覆盖进程发现、未确认账号不自动接入、桌面认证与重建持久化。真实 hook 接入与真实 QQ 登录在最新 smoke 中是 NOT RUN。
- **Docker arm64**：有构建输入，没有实际运行验证；不要标为已测试。
- **Linux Lite**：启动器、Node 基线与发行布局有检查；真实原生接入需在你的桌面验证。
- **Windows x64**：exe 已构建，未签名；真实 QQ 注入、登录与长期会话未验证。OOBE 式安装/配置教程暂缓；首次仍在控制台内完成说明阅读与改密，账号内核选择仍是实际接入步骤，不是额外的平台选择向导。

平台支持不等于账号一定可用；QQ 服务端会话、权限、桌面环境和网络都可能影响结果。

每次发行以[对应源码的 CI](https://github.com/NowLuma/NowLuma/actions)和[发行产物](https://github.com/NowLuma/NowLuma/releases)为准；历史通过记录不替代当前账号登录、桌面或消息投递验收。

## 发行与更新

- Linux 运行时包：`Nowluma-v<version>-linux-x64-lite.tar.gz`。
- Windows 运行时更新归档：`Nowluma-v<version>-win-x64-lite.zip`，不内置 Node。
- Windows 一键启动器：`Nowluma-win32-x64-<version>.exe`，未签名，内置 Node 24 与 .NET 自包含运行时。
- 发行包含 `LICENSE`、`LICENSING.md`、`EULA.md`、`PRIVACY.md` 与 `SHA256SUMS`。
- 更新来源可自动切换、GitHub 直连或指定镜像；检测结果不代表下载速度。
- 没有 npm 发布，也不使用 Docker Hub；镜像标签以实际发行记录为准。

构建成功、来源证明和校验和只证明文件来源与完整性，不证明 QQ 能登录、机器人会回复或长期运行稳定。

## 文档站点

- 18 章 × 2 语言，静态构建为 `/NowLuma/` 基路径和相对 `/demo/`。
- [公开文档](https://nowluma.github.io/NowLuma/)由项目的 Pages 部署提供。
- `/demo/` 只在构建包含模拟器时存在，使用模拟数据，不连接真实 QQ。

## 性能与外观

- 动效在首次设置与外观页面手动开启或关闭，不运行持续帧率检测；旧自动质量值迁移为完整玻璃，既有动效偏好保留。
- 磨砂玻璃跳过位移渲染，不改变手动动效选择；完整玻璃在支持的 Chromium 尝试真实背景折射。
- 高对比、系统减少透明或宿主接管保持可读的实色/宿主表面；系统减少动态效果仍约束移动。
- 验证记录区分像素折射、连续操作、设备帧率和真实账号；单元测试不证明 GPU 成本或省电。
