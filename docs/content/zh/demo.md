# 模拟练习模式

每篇教程顶部都有对应的引导练习，当前目标、操作提示和进度跟随该章节。需要重新练习时，用教学区域的重置入口；不必每次从完整登录流程开始。

![教学模拟器中的操作提示与控制台](/images/tutorials/simulator-guide.png)

_图：实际教学界面的示例数据；引导不会替你同意真实账号风险或发送真实消息。_

文档站点带一个 `/demo/` 练习环境，用模拟数据渲染控制台组件，适合先熟悉新工作台再操作真实实例。

每篇教程的内嵌模拟器会选择本章的操作路线；首次设置从登录开始，其他章节可直接使用预置示例账号。独立 `/demo/` 用于自由浏览，不替代章节引导。

## 打开方式

- 点击正文上方的 **加载模拟器**，按引导操作。收起不丢失进度，**重新开始** 才重置本章。操作结果未确认时不能跳到下一步。
- 模拟器使用当前章节的语言，可在 `/NowLuma/` 基路径或本地 HTTP 预览打开。
- 只使用页面提供的公开示例密码和验证码，不需要真实 QQ 账号或 OneBot 令牌。

## 能做什么

| 场景                                           | 对应章节                                    |
| ---------------------------------------------- | ------------------------------------------- |
| 看浮动主导航、顶栏、连接工作流和运行读数       | [工作台](overview.md)                       |
| 走完说明、访问密码、手动显示效果与内核四步设置 | [首次启动](first-run.md)                    |
| 看进程状态与接入确认的样子                     | [QQ 会话](qq-connection.md)                 |
| 看四种连接页签与保存状态                       | [机器人连接](onebot-config.md)              |
| 练日志预设、搜索与 TRACE 提示                  | [运行记录](logs.md)                         |
| 看接口调用、发送消息与活动记录                 | [调试工具](debug.md)                        |
| 看设置分类与保存/重启提示                      | [偏好设置：外观与账号](settings-console.md) |

模拟数据覆盖正常、空状态和错误分支，方便看清「已保存并应用」与「已保存，下次连接时应用」这类差别。

## 不能证明什么

- 看到「已连接」不代表你的 QQ 已登录，也不代表机器人能收到消息。
- 看到「发送成功」不代表真实账号会送达或对方会回复。
- 它不写入真实配置，不读取真实令牌，也不连接任何真实服务。
- 不能用来验证数据持久化、重启、权限、内核风险确认或桌面认证。
- 不能代替真实账号的封号/风控评估。

## 与真实控制台的区别

| 项目 | 练习模式           | 真实控制台                 |
| ---- | ------------------ | -------------------------- |
| 数据 | 固定模拟数据       | 你的账号、进程与连接       |
| 网络 | 不向真实服务发请求 | 读取本机服务与 QQ          |
| 账号 | 不需要             | 必须由你在 QQ 登录         |
| 保存 | 不落盘             | 写入配置，按提示生效或重启 |
| 内核 | 只演示界面         | 按真实 UIN 确认并持久化    |

练习环境里没有可绕过的隐藏入口；真实使用请按[首次启动](first-run.md)和[QQ 会话](qq-connection.md)操作。需要验证真实行为时，必须在真实账号与真实端点上测。
